## Native rig and geometry

`CompiledVehicleRig` validates and edits the parallel immutable skeleton arrays: local rest matrices, original model-space inverse binds, hashed names, u16 parents (255 means no parent), and 24-byte joint-local AABBs. It preserves original inverse binds when posing. Appending an unused bone adds all five arrays without changing old indices or growing a visual palette.

The native `C_VisualObject::SetWorldMatrices` at Mac `0x102000EA0` maps local render slots through the selected LOD's u16 palette to skeleton indices; 255 is unused. `SingleMeshData::GetSkinning` at `0x101FBF8D0` reads four weight bytes followed by four local index bytes. Decoded visual geometry may have been transformed by a part inverse bind; the renderer compensates using `inverse(geometryBind) * nativeInverseBind`. Blender exports each visual's rig in the same visual space, then converts pushed poses back to native model space before writing local matrices.

`C_SkeletonComponent::SkeletonUpdate` at `0x102055A80` transforms the immutable AABB array (native offset104, 24 bytes per bone) by each current model-space bone matrix, proving these AABBs are joint-local. `C_SkeletonDataHelpers::AddBone` at `0x102053E70` appends inverse/original matrices, parent, name and AABB vectors and reallocates mutable runtime tables.

Copied Bruno tests: pose save/reopen and byte-exact undo; append119th bone with model-space position and stable visual palettes; 18 per-visual Blender skeleton payloads preserve no-op and exact pose undo. ## Native Havok animation playback

`HavokAnimationClip` reads actual PC64 Havok2014.2 packfiles and the SDS outer class-name wrapper. Binding offsets: skeleton name16, animation pointer24, transform-track-to-bone short vector32/count40, blend hint80. An empty map is the native identity mapping. `hkaAnimationBinding` copy constructor at `0x100267230` and native track queries confirm the map. Additive blending is explicitly refused.

Uncompressed PC animation fields: duration20, transform tracks24, float tracks28, transform samples56/count64. Each hkQsTransform sample has translation16, quaternion16, scale16 bytes. Native `samplePartialWithDataChunks` at `0x103C0A580` linearly blends translation/scale and normalizes the shortest quaternion lerp.

Spline fields: frame count56, block count60, maximum frames per block64, mask size68, block offsets88, optional individual-track offsets120, packed data152. Native `sampleIndividualTransformTracks` at `0x103C0CBB0`, packed offset helper `0x103C43A90`, knot reader `0x103C0D480`, scalar readers `0x103C0DD00`/`0x103C0E2C0`, and rotation readers `0x103C0E890`/`0x103C0EC70` establish layout/alignment. Curves have u16 last-control index, u8 degree, byte knots, then static/min-max values and quantized control points. Managed playback evaluates degree1–3 B-splines directly (not frame-baked approximation).

Signed32 rotations are native octant polar/lattice coding (`unpackSignedQuaternion32`, `0x103C43450`):18-bit spherical lattice,10-bit scalar component,4 sign bits. Signed40 (`0x103C436E0`) uses three12-bit components,2-bit omitted component, and omitted sign bit38. Native constants confirm scalar normalization. All67 compressed ingame clips use modes0/1 (6776/536 first-block track masks); scalar8/16 modes are decoded.

The copied skeletons.sds supplies304 named Havok skeletons. All69 ingame clips (67 splines +2 interleaved) bind their actual prod_male/prod_female112-bone skeleton. Every original frame of every clip samples successfully, including the278-frame multi-block clip. Actual GPU tests render all69 midpoint poses and rewind byte-exact;67 change visibly and two5-frame clips have an unchanged midpoint. These human clips are never attached to an unrelated118-bone vehicle skeleton.

`AnimationPreviewWindow` provides a read-only clip list, play/pause and seek. `HavokAnimationPreview.Sample` resolves local tracks through the explicit map and hierarchy. MCP `AnimationOpen(archive,clip,time,playing)` uses non-activating windows. Native float/morph tracks, additive blending and rotation quantization modes2–5 are not yet applied. All shipped ingame skeleton-motion clips in the tested archive are covered.
