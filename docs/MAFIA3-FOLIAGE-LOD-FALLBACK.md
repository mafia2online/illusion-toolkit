# Vegetation renderer availability

The native group graph and native visibility evaluator remain unchanged. A separate renderer evaluator retains a coarse parent when any immediate child subtree has zero supported decoded meshes. This is an editor fallback, not a reproduction of the missing fine foliage representation. Manual visibility never contributes to coverage: hiding a fine mesh deliberately must not reveal its coarse substitute.

`CompiledSceneDocument.RefreshNativeLodRenderCoverage()` publishes actual decoded `Meshes` counts to the stable graph. `NativeLodGraph.IsRenderVisible` / `EvaluateRender` use that coverage; `IsVisible` / `Evaluate`, `ChildrenReady`, graph identities and native bounds snapshots retain their original semantics. Coverage updates validate the whole input before publication. Before any coverage is published, renderer queries preserve the native evaluator's behavior. `NativeLodRenderFallback` and `RenderFallbackGroups` report incomplete renderer coverage explicitly.

Copied Bayou block B demonstrates the issue. Parent `673B5CF420204E81` owns three `built_bc_bayou_block_b_baked_vegetation_*` Model frames; child `673B5CF420204E83` has no decoded Model meshes. The child completer `673B5CF420204E89` exists in the far SceneCollection resource and makes the native parent complete. Its group pointer is the only reflected raw field reference to this child across the loaded family. Native selection therefore hides the coarse models near the group even though this editor cannot draw a fine replacement. Renderer fallback retains those three models.

The survey also found empty Model fine groups in Downtown block A, EastHighland north block A and Frisco Fields block A. Fine foliage cannot safely be inferred from names or a completer alone. None of these cases establishes that the native fine scene is empty.
