## Native procedural paint cells

`C_PaintResource` (`709F6BD3`) owns entries associating an explicit scene-object GUID and visual-name hash with a paint object. Native `ActivateEntry` (`1023311A0`) resolves that identity and calls `C_PaintComponent::AddPaintObject` (`1020C1770`), which copies the live visual world matrix. Resource roots of the physical selected scene/LOD family activate these entries; shared dependency registries do not. There is no name-based model association. The owner terrain's native group (for the first Bayou entry, `673B5CF420204E7F`) is distinct from the vegetation child `...83`. Native completer readiness does not encode paint population, so the coarse fallback is retained.

`CompiledNativePaintField` captures immutable mapping, density, template and transform inputs for background generation. Bayou B yields 67 supported mesh profiles (54 native baked routes and 13 scene-object routes); 11 particle/effect profiles are explicitly refused. Current supported profiles require an unchained constant linear density filter, regular random spacing, an explicit CPU UV mapping/output and a supported rigid leaf template. Unknown inheritance, skeletal paint owners, fixed spacing and unsupported spawners are refused. Baked templates additionally require an identity rigid binding. Snapshot refresh never writes resources or changes ordinary scene root/mesh counts.

The native default context has radius 150, three additive density levels, and root cell size `(37.5,37.5,150)`. High quality scales radius and grid dimensions together. Cell construction, cofactor inverse and world-to-cell multiplication match original machine-code float operation order, including the reciprocal-rounding difference from a generic matrix inverse. The source clips canonical cells against `[-.5,.5]^3`, preserves native shared-vertex/fan/swap-delete ordering, returns to world space, hashes each world triangle and the exact UTF-8 layer-instance name, and applies its level density. Parent population gates refinement; additive ancestors remain active. Selection and fractional active counts use the separately verified native helper described in `MAFIA3-PAINT-TRANSFORMS.md`.

Native vertex translation is unsigned packed XY, packed Z masked by `7fff`, then quantum multiply and origin addition. The mesh-set compression padding is only a conservative render envelope, not a position bias. Native half-UV translation flushes exponent-zero values to positive zero and expands exponent 31 as a finite float; ordinary IEEE Half conversion would differ. Original copied translator code matches 131,072 UV half components and 30,000 random position components bit-exact. Rasterization clamps image coordinates to `[-100,100]`. Original face-normal code matches 10,000 triangles / 30,000 components bit-exact, including tiny triangles and first signed-axis fallback (digest `D69C676B622393B7DA1DA5CCCAA8ADE8C039150761C6226BE4E2B4A55D2AD89B`).

Templates with fewer than 256 first-stream vertices take the native 16-bin baked route; larger templates use position-hashed SO transforms. The native game shuffles points with runtime RNG not serialized in these assets. The preview therefore exposes an **editor shuffle seed**: the accepted native point set is preserved, but the order and resulting baked-bin assignment are explicitly editor-repeatable, not claimed to reproduce a particular game's runtime shuffle. Bins are assigned from the full point count before active-prefix truncation. The preview uses hardware instances of the native pre-requantization transforms; native packed-buffer requantization, wind and foliage pixel-shader parity are not claimed.

Baked LOD queries use one fixed full-cell AABB, expanded by the native mesh-set compressed-position envelope radius times maximum scale. The radius comes from `min=origin-(8,8,4)*q`, `max=min+(65536,65536,32768)*q`; source internal squared-distance cutoffs are retained. All levels share the full ordered instance list. Changing the active prefix neither re-clips nor re-bins the cell.
