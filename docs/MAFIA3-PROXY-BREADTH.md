# Generalized linked-proxy preparation coverage

Preparation is selected by typed native ownership and geometry invariants, not by an allowlist of two stock group GUIDs or fine-object counts. The parent must be complete through its actual fine-child completer, own exactly one supported fine leaf, and have one active SceneCollection-owned coarse render root. Every fine model participant must be loaded and active. Unsupported hierarchy, participant, geometry, binding, material and dependency layouts remain explicit refusals. This does not make arbitrary actor/foliage representations editable.

## Durable non-stock authoring cases

TestCompiledLinkedProxyBreadth verifies Bridge A (seven fine objects) and Downtown unique bridge B (one fine object with six visuals). Each test creates its own archive copies and mirror, then inspects, prepares, pairs a fine/far movement, saves, reopens the validated mapping and restores the source exactly.

The rebuilt destination is compressed into a new far-only SDS, loaded without either fine archive, and independently decoded. Every generated lowest-LOD position, normal, tangent, binormal, UV, color, secondary UV, influence, index, world matrix and material range matches its source counterpart. Every unique native vertex/index buffer payload matches byte-for-byte after compression. With no fine-child completer available, the native parent correctly keeps its coarse fallback.

Both cases pass16 checks in total, including exact original GENR/texture/manifest undo, mapping removal, and unchanged original/copied input archive hashes. All writes are confined to unique copied fixtures; installed game files are read only when initially copying the new district trios. The 608-frame survey did not find a real native Kit ancestor for a fine member, so no synthetic hierarchy is presented as an actual ancestor acceptance test.
